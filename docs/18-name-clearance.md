# 18 — Name Clearance: Hikari

Searched 2026-09-22 against **TMview** (the EUIPO-operated network database that includes the UK register), Verisign/Nominet RDAP for domains, and Companies House.

**Not legal advice.** This is a preliminary screen. The register entries are real; the conclusions drawn from them need a trade mark attorney.

## ⚠️ The finding: "HIKARI" is already registered in Class 14

| | |
|---|---|
| **Mark** | **HIKARI** |
| **Number** | UK00917478348 |
| **Class** | **14 — jewellery** |
| **Status** | **Registered** |
| **Filed / Registered** | 14 Nov 2017 / **20 Dec 2019** |
| **Owner** | **D.C.K. CONCESSIONS LIMITED** |
| Owner status | Companies House **02715822 — Active**, incorporated 1992 |

**Class 14 is precisely our goods class.** And DCK Concessions is a live UK company in the jewellery and accessories concession trade — not a dormant shell.

This is not only "we probably cannot register Hikari in Class 14". It is "**using** Hikari for jewellery in the UK may infringe a live registration". Refusal is the cheap outcome; a letter is the expensive one.

## Options

1. **Change the name.** Cleanest, and cheapest *now* rather than later.
2. **Add a word** — "Hikari Vintage", "Hikari London". **Weak.** Where the distinctive element is identical and the goods are identical, a descriptive addition usually does not escape infringement.
3. **Revocation for non-use.** The mark registered in Dec 2019, so it is past the five-year grace period and *could* be revoked if DCK has not genuinely used it. But DCK is active and in this exact trade, so use is plausible. Costs money, takes months, uncertain.
4. **Coexistence or licence** — approach DCK. Possible; rarely quick or cheap.
5. **Risk-assess and proceed** — only on an attorney's reading of the actual specification.

### Recommendation

**Treat the name as unresolved, and decide before any further spend on brand.** Get an attorney to pull the Class 14 specification and the Class 35 wording — one hour, well inside the £300–800 already budgeted at [12](12-build-cost.md). That hour decides between "change the name" and "proceed", and it is the cheapest hour in the plan.

### What is *not* lost if the name changes

Almost nothing, which is the point of having checked now:

- The **palette** ([08](08-brand.md)) is name-independent
- The **grain, scroll-colour and layout systems** ([04](04-site-ia.md), prototypes) are name-independent
- The **lockup's proportional system** — kanji at 1.30 cap height, one weight step below the Latin, rule at 1.00 C, 0.28 em tracking ([10](10-logo.md)) — **transfers to any kanji + Latin name.** Only the glyphs change.
- Positioning, customer, pricing, platform, tax: all untouched

The switching cost today is one SVG and a domain. In six months it is the domain, the handle, the packaging, the SEO, and any press coverage — some of which cannot be recovered at all.

## Handles — could not be verified from here

Instagram returns a login redirect (HTTP 302) to automated requests, so `@hikari`, `@hikarivintage`, `@hikari.vintage`, `@hikarilondon`, `@shophikari` and `@hikari.archive` are **unverified**. Xiaohongshu likewise.

**Two minutes each, manually:** open `instagram.com/<handle>` in a browser — "Sorry, this page isn't available" means free. Check Instagram, TikTok, Pinterest and Xiaohongshu for whichever name survives clearance. Handles matter disproportionately here because the Edition strategy ([05](05-social.md)) runs on Instagram.
