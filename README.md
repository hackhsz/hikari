# Hikari — 光

An independent resale house for vintage designer jewellery: sourced in **Japan**, sold into the **UK**.

- **Product:** vintage / archival costume jewellery — Christian Dior, Chanel, Givenchy, YSL, Nina Ricci, Grosse, and the better mid-century American makers.
- **Price band:** £100–300 retail.
- **Supply:** Japan (auction, reuse-chain and wholesale channels).
- **Demand:** United Kingdom first.
- **Stock model:** one-of-one. Every piece is a single SKU.
